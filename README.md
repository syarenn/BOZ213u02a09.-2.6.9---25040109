# Python Basit Girdi ve Çıktı – Dört İşlem

## 1. Proje Ne Yapar?

Bu çalışma, Nesne Tabanlı Programlama dersi kapsamında tüm öğrencilere verilen ortak bir Python laboratuvar uygulamasıdır.

Program, kullanıcıdan iki ondalıklı sayı alarak dört temel aritmetik işlemi gerçekleştirir:

- Toplama
- Çıkarma
- Çarpma
- Bölme

Hesaplanan sonuçlar konsol ekranında görüntülenir.

## 2. Proje Neden Faydalıdır?

Bu laboratuvar çalışması, Python programlama dilinde temel girdi ve çıktı işlemlerinin öğrenilmesini amaçlamaktadır.

Çalışma sayesinde:

- `input()` fonksiyonuyla kullanıcıdan veri alma,
- `float()` fonksiyonuyla veri tipi dönüşümü yapma,
- Aritmetik operatörleri kullanma,
- `print()` fonksiyonuyla sonuçları görüntüleme,
- Değişkenlerle matematiksel işlemler gerçekleştirme

becerileri pekiştirilmektedir.

## 3. Kullanıcılar Projeyi Nasıl Çalıştırabilir?

### Kullanılan Teknolojiler

- Python 3
- Python IDLE

### Programın Çalıştırılması

1. Python IDLE açılır.
2. `main.py` dosyası açılır.
3. F5 tuşuna basılarak program çalıştırılır.
4. Kullanıcıdan birinci ve ikinci sayı istenir.
5. Girilen sayılarla dört temel aritmetik işlem gerçekleştirilir.
6. İşlem sonuçları konsol ekranında görüntülenir.

### Örnek Girdi

Birinci sayı: 10

İkinci sayı: 2

### Beklenen Çıktı

```text
Enter the first number: 10
Enter the second number: 2
Addition: 12.0
Subtraction: 8.0
Multiplication: 20.0
Division: 5.0

That's all, folks!
```

### Kullanılan Python Yapıları

| Python Yapısı | Görevi |
|---|---|
| `input()` | Kullanıcıdan veri alır. |
| `float()` | Girilen veriyi ondalıklı sayıya dönüştürür. |
| `print()` | Sonuçları ekrana yazdırır. |
| `+` | Toplama işlemi yapar. |
| `-` | Çıkarma işlemi yapar. |
| `*` | Çarpma işlemi yapar. |
| `/` | Bölme işlemi yapar. |
| `\n` | Yeni satıra geçilmesini sağlar. |

### Dikkat Edilmesi Gerekenler

Bölme işleminde ikinci sayının sıfır olmaması gerekir. Aksi takdirde Python `ZeroDivisionError` hatası verir.
